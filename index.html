How it works

One CSV in, a worked call list out.

Six deterministic steps turn a raw listings export into a ranked shortlist — no manual spreadsheet triage, no guessing which building to call first.

01 · INGEST

Upload the export

Listing name, host, coordinates, room type, price, reviews, availability — any Inside Airbnb‑style CSV.

02 · FILTER

Isolate entire homes

Keeps the segment relevant to co‑hosting; shared rooms and hotel listings fall away automatically.

03 · CLUSTER

Group into buildings

Proximity plus shared‑host detection finds real buildings — without folding large managers' portfolios into one false "building."

04 · SCORE

Rank the leads

Weighs low/declining occupancy, building size, and whether the address is already in your managed portfolio.

05 · ESTIMATE

Quote the gap

A defensible $/mo revenue‑uplift figure — only where occupancy is well evidenced, never inflated.

06 · EXPORT

Push to Airtable

The current view lands directly in the Prospecting base, staged and ready to work.

New — answer it on the spot

"What would this address earn?" Answered mid‑call.

Type any address into the tool and it finds the nearest buildings already charted, then blends their rate and occupancy into a rough estimate — right while you're on the phone with an owner.

  • Comps‑based, not a black box. Every estimate shows exactly which nearby buildings it's drawn from, and how far away they are.
  • Honest misses. If nothing's been surveyed near that address yet, it says so — no number is ever guessed from thin air.
  • Free to run. Geocoding is OpenStreetMap; comps come from data already charted. No paid API required to start.
