# Airbnb Prospector — historical pilot

This repository preserves a static short-stay prospecting concept and historical pilot survey. It contains presentation copy and a chart of fixed suburb aggregates; it does not import listings, score new leads or save CRM records.

The historical figures do not establish current listing status or confirmed owner income. Ask the business development manager for current research and the approved CRM handoff.
