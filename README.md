# Airbnb Prospector — historical pilot

This repository preserves a static short-stay prospecting concept and the September 2026 Inside Airbnb pilot survey. It contains presentation copy and a chart of fixed suburb aggregates; it does not import listings, score new leads or save CRM records.

The historical figures do not establish current listing status or confirmed owner income. Ask the business development manager for current research and the approved CRM handoff.

Public historical page: <https://dylan888a.github.io/AirBnB-Prospector-/>.

For maintainers, implementation and the manual CRM handoff guide continue in the agency's private maintained project. Request access through the business development manager. Private project links are omitted from this public overview.
